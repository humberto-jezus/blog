# Humberto Jezus — Technical Blog

A modern, cloud-native engineering and technical blog exploring Software Engineering, Distributed Systems, Cloud Architecture, and Artificial Intelligence.

🌐 **Live Website:** [https://www.humbertojezus-techblog.com](https://www.humbertojezus-techblog.com)

---

## ⚡ Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express
- **Deployment:** Containerized, cloud-native architecture with automated CI/CD pipeline
- **Security:** Hardened container runtime, automated TLS/HTTPS encryption

---

## 💻 Local Development

### Prerequisites

- Node.js (v20+ recommended)
- npm

### Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```

Open `http://localhost:3000` in your browser.
